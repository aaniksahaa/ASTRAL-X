# - Use generic algorithm option flags everywhere: --opts / --opts-list
# - For ASTRAL-X, result-affecting settings are stored under:

#   or for A10K:
#     astralx_outputs/<tree_type>/<setting>/...
# - Verbosity flags such as -v / -vv do not affect the setting name
# - Common setting names:
#     --opts "--search-mode local"  -> search-mode_local
#     --opts "--search-mode full"   -> search-mode_full
